# PowerConnect 28xx page catalogue

Field names below were extracted from sanitized captures of a PowerConnect 2816 web UI.
Suffixes: `$query` current row, `$add` new row, `$repeat?N` / `$repeat11?N` table row, `$scalar` global, `$VT` type metadata.
Row status values used by the device: 1 modify, 4 createAndGo, 6 destroy.
Port lists (`Type=101`) are hex bitmaps, MSB-first, bit index = ifIndex-1. g1-g16 are ifIndex 1-16. ch1-ch8 are ifIndex 1000-1007.
